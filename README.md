# The Talent Factor
Présentation universitaire en français — React, TypeScript, Tailwind CSS et Vite.

## Lancer
Avec Node.js installé : `npm install`, puis `npm run dev`. Ouvrir l’URL indiquée.
Production : `npm run build`, puis `npm run preview`.

## Utiliser
- Flèches gauche/droite, Page précédente/suivante ou espace : navigation.
- Début / Fin : première / dernière diapositive.
- S : sommaire ; N : notes orales ; F : plein écran ; Échap : fermer les panneaux.
- Exporter PDF : ouvre l’impression des dix diapositives. Choisir « Enregistrer au format PDF », sans en-têtes ni pieds de page, avec les arrière-plans activés. Format 16:9 défini dans la feuille de style.

Durée des notes : 9 minutes. Les notes et les sources sont consultables sur chaque diapositive et exclues de l’impression. Aucun chiffre statistique n’est utilisé. Le cas tunisien est explicitement fictif. Les références sont dans src/data.ts. Les illustrations sont des SVG originaux intégrés. Inter est chargé depuis Google Fonts avec Arial en secours. Respect du réglage de réduction des animations.
